# Onboard New Team Member

## Goal
Create accounts and grant access for a new team member joining the engineering team.

## Steps

1. Get the new hire's information from the onboarding request
2. Create a GitHub account for the new hire
3. Add them to the engineering team on GitHub with member access
4. Create a Slack account with their email
5. Invite them to the #engineering channel
6. Send a welcome email with account details

## Validation

- GitHub account is active and user received invite email
- User is member of 'engineering' team on GitHub  
- Slack account exists and invitation was sent
- User has access to #engineering channel
- Welcome email was successfully delivered
